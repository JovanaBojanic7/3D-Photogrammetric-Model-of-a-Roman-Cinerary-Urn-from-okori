# 3D-Photogrammetric-Model-of-a-Roman-Cinerary-Urn-from-okori
3D Photogrammetric Model of a Roman Cinerary Urn from Čokori  Digital documentation and 3D reconstruction of a Roman travertine cinerary urn (lid missing), dated to the 2nd–3rd century AD. Discovered near Čokori, the artifact is currently housed in the Museum of the Republic of Srpska in Banja Luka.
